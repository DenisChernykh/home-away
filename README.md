# Home Away — аренда жилья

Веб-приложение для поиска жилья, размещения объектов и управления бронированиями.

## Возможности

- Каталог объектов, карточки, избранное и карта.
- Профиль пользователя и управление своими объектами.
- Бронирования и checkout на Next.js, Prisma и Clerk.

## Инженерные акценты

- Реализация связанных пользовательских сценариев маркетплейса.
- Работа с авторизацией, формами и реляционной моделью данных.
- Интеграция внешних сервисов с серверным React-приложением.

## Стек

React, Next.js, TypeScript, Prisma, Tailwind CSS, Clerk.

## Навигация по коду

- [app/](app/) — приложение.
- [prisma/](prisma/) — схема данных и миграции.

## Разработка

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
```

Параметры окружения перечислены в [.env.example](.env.example). Локальные значения задаются вне Git.
